## Run locally
1. Install Python 3.10+.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start Jupyter:
   ```bash
   jupyter notebook
   ```
4. Open the notebook and use **Kernel → Restart & Run All**.

The notebook uses a synthetic RideNow trips dataset generated inside the notebook; no external dataset download is required.
